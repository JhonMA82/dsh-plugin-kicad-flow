# Roadmap

Este documento define los **límites de alcance explícitos** del plugin. Son listas de exclusión: capacidades que deliberadamente **NO** se implementan en cada nivel. Todo lo que no esté listado aquí como no-implementable mantiene el flujo actual de Nivel 1 (esquemático → PCB → routed → manufacturing).

---

## Roadmap Nivel 2

NO implementar ahora:

- current-aware trace sizing;
- thermal optimization;
- creepage avanzado;
- isolation rules;
- automotive-specific rules;
- switching loop optimization;
- complex keepouts;
- advanced layer stack;
- automated power integrity.

## Roadmap Nivel 3

NO implementar:

- controlled impedance solver;
- differential pair tuning;
- length matching;
- DDR;
- PCIe;
- USB3;
- SerDes;
- RF;
- antenna design;
- SI/PI;
- external electromagnetic solvers.
